## (Livro de Algoritmos)

**Repositório:** Lista de exercícios de programação em Kotlin.

## Sobre o projeto

Este repositório contém 120 questões do livro de Introdução a Programação: 500 Exercícios Resolvidos desenvolvidas utilizando a linguagem de programação Kotlin, como parte das atividades acadêmicas da disciplina.

## Organização

As atividades estão organizadas em pastas individuais, identificadas pela numeração de cada questão:

- Questão 1.kt
- Questão 2.kt
- Questão 3.kt
- ...
- Questao 120.kt

## Tecnologias utilizadas

- Kotlin
- IntelliJ IDEA

## Objetivo

Praticar os conceitos de lógica de programação e desenvolvimento de software utilizando Kotlin.
